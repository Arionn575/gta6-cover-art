Neon Cover Studio — an offline browser web app that turns any photo + caption into GTA-style multi-panel poster cover art, with a Vice City neon-sunset grade, exported as PNG.

Upload a photo (or use a sample), pick one of 3 panel layouts, pan and zoom each panel, letter your caption in bold condensed type with 4 colour themes, tune the sunset grade, and export at 1080×1080, 1080×1350, or 1920×1080. Everything runs locally in the browser — no uploads, no network. All art and lettering are original.

## Run it

```sh
node serve.ts
```
